합성 실패 재생

실제 Riot 원천을 망가뜨리지 않고 다섯 실패를 합성 재생합니다. 실패 중에는 마지막 정상값을 보존하고, 정상 복구 버튼으로 다시 fresh 상태를 확인할 수 있습니다.

클라이언트에는 Riot API 키를 넣지 않습니다. Riot 원천 데이터를 서버에서 가져오고, KST 날짜 기준으로 하루 한 건만 보존합니다.
